# comensee

Website for Come n See, an East London art collective and film club run by Veronika Butkevich (@vmbut). Instagram: [@_come_n_see_](https://www.instagram.com/_come_n_see_/). Contact: comensee.info@gmail.com.

A static site in the same style as `../vmbutkevich`: plain HTML, one stylesheet, one script, no build step and no dependencies.

## Assets

- `img/wordmark-red.png`: hand-drawn red "come n see" wordmark (from the vmbutkevich home page).
- `img/poster-come-n-see.jpg`: yellow "come n see" poster (from the vmbutkevich Come n See page).

Event photos from Instagram are still to be added. Instagram blocks automated downloads, so they have to be saved by hand into `img/`.

## Preview locally

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000/>.
